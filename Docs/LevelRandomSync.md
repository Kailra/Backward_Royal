# 맵 내 랜덤 기물 서버·클라이언트 동기화

맵에 **랜덤으로 생성되는 기물(오브젝트)**이 서버와 클라이언트에서 **같은 위치**에 보이도록 하는 방법입니다.

---

## 원인

- 랜덤 생성 로직이 **서버와 클라이언트 각각**에서 돌면, 서로 다른 랜덤 시드/순서 때문에 **위치가 달라집니다**.
- 해결: **서버 한 곳에서만 결정**하고, 그 결과를 클라이언트에 맞추면 됩니다.

---

## 방법 1: 서버에서만 스폰 + 복제 (권장)

**기물이 액터(AActor)로 스폰되는 경우** 가장 확실한 방법입니다.

1. **스폰은 서버에서만**  
   - C++: `if (HasAuthority()) { ... SpawnActor ... }`  
   - 블루프린트: **Authority** 분기 또는 **Switch Has Authority** → **Authority** 쪽에서만 스폰

2. **스폰된 액터가 복제되도록**  
   - C++: 스폰할 클래스에서 `bReplicates = true` (기본값이면 설정)  
   - 블루프린트: 해당 액터 블루프린트 **Replication** → **Replicates** 체크

이렇게 하면 서버가 생성한 기물만 있고, 그 액터가 복제되어 **모든 클라이언트가 같은 위치의 같은 기물**을 보게 됩니다.

---

## 방법 2: 공용 랜덤 시드 사용

**같은 랜덤 순서**를 서버와 모든 클라이언트에서 쓰고 싶을 때 사용합니다.

- **GameState**에 서버가 맵 로드 시 정한 **Level Random Seed**가 복제됩니다.
- 이 시드를 사용해 랜덤을 돌리면, **호출 순서가 같을 때** 서버와 클라이언트 결과가 같습니다.

### C++에서 사용

```cpp
// GameState에서 레벨 랜덤 스트림 가져오기
if (ABRGameState* GS = GetWorld()->GetGameState<ABRGameState>())
{
    FRandomStream Stream = GS->GetLevelRandomStream();
    float RandVal = Stream.FRand();           // 0~1
    int32 RandInt = Stream.RandRange(0, 10);   // 0~10
    FVector RandomLoc = ...; // Stream으로 위치 계산
}
```

- **주의**: `GetLevelRandomStream()`은 매번 **같은 시드로 새 스트림**을 만들므로, **한 액터가 한 번에 필요한 만큼만** 쓰거나, 호출 순서를 서버/클라이언트가 **완전히 동일**하게 유지해야 합니다.

### 블루프린트에서 사용

- **Get Level Random Seed** (GameState에서) 로 시드를 가져옵니다.
- 엔진 기본 **Random** 노드는 시드를 받지 않으므로, **같은 결과**를 내려면:
  - **방법 1**처럼 **서버에서만 스폰 + 복제**를 쓰거나,
  - 시드를 사용하는 **커스텀 블루프린트 함수/노드**를 C++에서 노출해 사용하는 방식을 권장합니다.

---

## 요약

| 상황 | 권장 |
|------|------|
| 기물을 **액터로 스폰** | **서버에서만 스폰** + 액터 **Replicates** 체크 |
| **절차적/수식**으로 위치만 맞추고 싶음 | GameState **Level Random Seed** + C++에서 **GetLevelRandomStream()** 사용 (호출 순서 동일할 것) |

서버 플레이어가 보는 랜덤 기물을 기준으로 클라이언트도 같이 보이게 하려면, **방법 1(서버 전용 스폰 + 복제)**을 우선 적용하는 것이 가장 안정적입니다.
